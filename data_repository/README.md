Place local evidence for an investigation in this directory, then build the
index from the web app.

Suggested evidence includes:

- manufacturer manuals and extracted OCR text
- datasheets and industrial protocol specifications
- schematics, wiring diagrams, teardown photos, and annotations
- source code, firmware notes, build logs, or configuration exports
- forum captures, vulnerability advisories, standards, and academic papers

Keep classified or sensitive material on the offline workstation where the app
is running. The assistant stores its index, profile, and chat memory locally in
`.assistant_state/`.
